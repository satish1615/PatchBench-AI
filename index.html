Expected ZIP structure

benchmark-task.zip
├── task.json
├── states/
│   ├── before/       # original source files
│   └── after/        # approved result files
├── tests/
│   ├── fail2pass/    # focused regression tests
│   └── pass2pass/    # behavior preservation tests
├── Dockerfile        # optional, recommended
└── test.sh           # optional, recommended

The browser checks repository layout, file changes and declared test names. Use a separately isolated CI/container runner to verify actual behavior offline.

Welcome to PatchBench AI

Validate benchmark packages before you submit them to a coding-agent evaluation pipeline.

  1. Choose a sample to see the checks in action, including a deliberately broken task.
  2. Upload a ZIP containing task.json and matching before/after source files.
  3. Review findings, correct issues and download a portable report.

Privacy: validation runs locally in your browser. The tool does not execute code, contact an LLM or upload files.
